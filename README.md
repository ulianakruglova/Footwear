# Приложение «Обувь» (ООО «Обувь»)

## Описание
Информационная система для магазина по продаже обуви.
Позволяет просматривать актуальную информацию об остатках товаров на складах.

## Технологии
- **Язык программирования:** Python 3.13
- **GUI-фреймворк:** PyQt5 + Qt Designer
- **СУБД:** PostgreSQL 17
- **Драйвер БД:** psycopg2-binary

## Функционал
- **Авторизация** — логин/пароль из БД
- **Роли:**
  - **Гость** — просмотр товаров без фильтрации
  - **Авторизированный клиент** — просмотр товаров без фильтрации
  - **Менеджер** — просмотр товаров с фильтрацией, сортировкой, поиском
  - **Администратор** — просмотр товаров с фильтрацией + CRUD

## Установка и запуск

### 1. Установить Python
Скачать Python 3.13: https://www.python.org/downloads/

### 2. Установить PostgreSQL
Скачать PostgreSQL 17: https://www.postgresql.org/download/

### 3. Установить зависимости
```bash
pip install -r requirements.txt
```

### 4. Создать базу данных
```bash
psql -U postgres -c "CREATE DATABASE shoe_store;"
psql -U postgres -d shoe_store -f shoe_store.sql
```

### 5. Настроить подключение
Открыть `config.py` и указать свои данные:
```python
DB_CONFIG = {
    'host': 'localhost',
    'port': 5432,
    'database': 'shoe_store',
    'user': 'postgres',
    'password': 'postgres'
}
```

### 6. Запустить приложение
```bash
python main.py
```
